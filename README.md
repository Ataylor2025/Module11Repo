# StudySprint AI – Final Web Project

StudySprint AI is a dynamic and responsive web application focused on improving student productivity through task planning, focus sessions, and motivational API-driven insights.

## Features

- **Dynamic Task Manager:** Add, prioritize, and complete study tasks.
- **Interactivity:** Includes real-time task updates and an interactive Pomodoro timer.
- **API Integration:** Fetches educational motivational quotes from a public API (`api.quotable.io`).
- **Responsive Design:** Optimized layouts for mobile, tablet, and desktop.
- **PWA Foundation:** Includes a web manifest and service worker for offline-ready behavior.
- **Innovation:** Combines productivity tooling with modern web APIs and installable app capabilities.

## Technologies Used

- HTML5
- CSS3 (responsive media queries)
- JavaScript (ES6+)
- Fetch API
- Service Worker + Web App Manifest

## Local Setup

```bash
python3 -m http.server 8000
```

Then open:

`http://localhost:8000`

## Deployment

The app is configured to be deployed on **GitHub Pages** via the repository workflow.
You can also deploy to **Netlify** or **Vercel** by connecting the repository and publishing the root directory.
